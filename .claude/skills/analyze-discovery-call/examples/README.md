# Examples — teach the skill what good looks like

After each real assessment, drop in a pair of files:

```
examples/
  2026-07-acme-landscaping.transcript.md   # the discovery call transcript
  2026-07-acme-landscaping.client-data.json # the final, human-QA'd report data
```

The skill reads these before analyzing a new transcript. The first 2–3
assessments will need manual tool substitutions; by assessment 4–6, with
examples in place, the output should be close to copy-paste.
